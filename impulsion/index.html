Impulsion

Version 1.2.139.

Télécharger Impulsion
Première installation
  1. Toucher le bouton de téléchargement, puis ouvrir le fichier téléchargé.
  2. Autoriser le navigateur (Firefox, Chrome…) à installer des applis si Android le demande.
  3. Si Play Protect avertit : « Plus de détails » › « Installer quand même ».
Ensuite

L’appli cherche elle-même une version plus récente à chaque ouverture : carte « Mise à jour », bouton « Installer la version… ». Plus besoin de revenir ici.

Sur le PC

Le programme Impulsion montre les textes des bulletins, à copier dans iMuse, par lieu ou par étiquette. Il lit les notes dans pCloud Drive, sans rien y changer : les retouches se font au téléphone.

Télécharger pour Windows
  1. Ouvrir le fichier téléchargé. Si Windows avertit (« Windows a protégé votre ordinateur ») : « Informations complémentaires » › « Exécuter quand même ».
  2. Ouvrir Impulsion depuis le menu Démarrer. La première fois, choisir le dossier Impulsion de pCloud Drive (d’habitude P: › Applications › Impulsion) s’il ne le trouve pas seul.
  3. Une nouvelle version s’annonce dans le programme : la télécharger ici, et l’installer par-dessus.

Version 1.0.3. Linux : paquet .deb (Debian, Ubuntu…) ou archive .tar.gz (lancer Impulsion/bin/Impulsion).
